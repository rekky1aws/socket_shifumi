# Test Shifumi Websocket
Petit test d'un shifumi en ligne pour me remettre au code NodeJS + Express + Socket.io.
Toujours dans le but de faire une appli complète de jeux de societé. Cette fois ci on s'attaque au système de salles qui permettent d'avoir plusieurs parties qui fonctionnent en même temps.

## Commands
Install dependencies :
```bash
npm install
```

Start the server :
```bash
npm run dev
```
Server now runs on port 3000.
